Why it exists

A bookmark folder is where saved posts go to die. You save thousands of notes and never open them again; the web version changes, authors delete posts, accounts get restricted. What you thought you had saved was only a link.

RedLink writes the body text, images, videos, tags, comments and timestamps to your own disk as Markdown — permanent, searchable, linkable.

What it does

  • Five sync sources: bookmarks, likes, own posts, keyword search results, subscribed creators
  • Complete capture: body text, hashtags, @ mentions, original images, mp4 videos, top-level and nested comments
  • Standard output: Markdown with YAML frontmatter, media embedded via ![[...]]
  • Optional AI: auto-categorisation, auto-tagging, topic reports (bring your own OpenAI-compatible API)
  • Scheduled sync: stops automatically when the login expires

Install

Three static files, no dependencies. Put them in .obsidian/plugins/redlink/ inside your vault, restart Obsidian, then enable RedLink.

manifest.json
main.js
styles.css

# target directory (the folder name must be "redlink")
<your vault>/.obsidian/plugins/redlink/

Direct downloads: manifest.json · main.js · styles.css

Or clone the repository:

cd <your vault>/.obsidian/plugins
git clone https://github.com/boaleiyt/redlink.git redlink

FAQ

What is RedLink?

A free, open-source (MIT) Obsidian plugin that syncs Xiaohongshu bookmarks, likes, posts, keyword search results and subscribed creators into a local vault as Markdown, including images, videos and comments.

How do I export my Xiaohongshu bookmarks?

Install RedLink in Obsidian, scan the QR code to log in, pick a root folder, and press Sync. Notes land under Bookmarks/, media under Media/.

Can I back up saved posts before the author deletes them?

Yes — that is the main use case. Everything is downloaded to your disk, so the local copy survives deletion of the original or changes to your account. Auto-sync keeps it incremental.

Does it save posts as Markdown I can use in Obsidian?

Yes. Each note is a .md file with YAML frontmatter, body text, embedded media and a comments table, fully searchable and linkable inside Obsidian.

Is RedLink free?

Yes. MIT licensed, no quotas, no paywall, no crippled tier. Donations are optional and unlock nothing.

Does it work on mobile or iPad?

No. It is a desktop-only plugin (isDesktopOnly is true) for Obsidian on Windows, macOS and Linux.

Do I have to give it my Xiaohongshu password?

No. Login uses the official QR flow; the cookie is stored locally in data.json. Requests go directly to Xiaohongshu with no third-party relay, and only content visible to your own account is read. Subscription pulls use randomised delays, but no automation can guarantee it never trips risk controls.

How is this different from xhs2obsidian?

RedLink is a fork of ytf606/xhs2obsidian. The signing and request-interception logic comes from the original author; RedLink rebuilt the UI, fixed timer lifecycle and timeouts, added image integrity checks and standardised note naming, and removed the quota and payment logic.
