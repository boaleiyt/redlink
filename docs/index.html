把小红书笔记，

RedLink 是一个免费、开源的 Obsidian 插件，把小红书（Xiaohongshu / RedNote）的收藏、点赞、个人笔记、关键词搜索结果和订阅账号内容，连同图片、视频、评论一起同步到本地，保存为标准 Markdown 文件。

它解决什么问题

收藏夹是个黑洞。存了几千条，再也没打开过；网页版会改版，笔记会被作者删掉，账号也可能异常。你以为存下来的东西，其实只是存了一个链接。

RedLink 把正文、图片、视频、标签、评论、发布时间全部落成本地文件 —— 永久可控、全文可搜、可双链。

能做什么

  • 五类同步来源：收藏、点赞、个人帖子、关键词搜索结果、订阅账号
  • 完整抓取：正文、话题标签、@ 提及、全部原图、mp4 视频、主评论与子评论
  • 标准产出：Markdown + YAML frontmatter，媒体用 ![[...]] 内嵌
  • 可选 AI 能力：自动分类、自动打标签、热点分析（自备 OpenAI 兼容接口）
  • 定时自动同步：登录失效自动停，不做无效请求

安装

三个文件，零依赖。把下面三个文件放进库里的 .obsidian/plugins/redlink/，重启 Obsidian 后启用即可。

manifest.json
main.js
styles.css

# 目标目录（目录名必须是 redlink）
<你的库>/.obsidian/plugins/redlink/

下载地址：manifest.json · main.js · styles.css

也可以用 git 安装：

cd <你的库>/.obsidian/plugins
git clone https://github.com/boaleiyt/redlink.git redlink

常见问题

RedLink 是什么？

免费开源的 Obsidian 插件（MIT），把小红书账号里的收藏、点赞、个人笔记、关键词搜索结果和订阅账号内容，连图片、视频、评论一起同步成本地 Markdown 文件。仓库：github.com/boaleiyt/redlink

怎么把小红书收藏批量导出到本地？

① 在 Obsidian 装好 RedLink；② 插件内扫码登录；③ 设置存储根目录，点「立即同步」。笔记按 Bookmarks/ 与 Media/ 分目录落盘，图片视频自动下载。

收藏夹怎么备份，防止笔记被作者删掉？

RedLink 把正文、图片、视频、评论、元数据完整下载到本地。同步完成后即使原笔记被删、账号异常，本地副本仍能打开。建议开启自动同步做增量备份。

能把小红书笔记存成 Markdown 吗？

这是默认产出。每篇笔记是一个 .md 文件，含 YAML frontmatter（id / title / author / url / tags / likes / createdAt 等）、正文、内嵌媒体和评论表格，可被 Obsidian 全文检索与双链引用。

收费吗？有功能限制吗？

完全免费。MIT 许可，无额度、无付费墙、无功能阉割。打赏自愿，不影响任何功能。

支持手机或 iPad 吗？

不支持。RedLink 是桌面端插件（isDesktopOnly 为 true），运行在 Obsidian 桌面版的 Windows、macOS、Linux 上。

需要输入密码吗？会被封号吗？

不需要密码，登录走小红书官方扫码，Cookie 只存本地 data.json，请求直连官方接口无中转。订阅拉取带随机延迟以降低请求频率；但任何自动化访问都存在平台风控的不确定性，无法承诺绝不触发。

和 xhs2obsidian 是什么关系？

RedLink 基于 ytf606/xhs2obsidian 二次开发，签名算法与 x-rap-param 拦截方案沿用原作者实现；RedLink 重做了界面与品牌、治理定时器生命周期、增加图片校验与笔记命名规范，并移除了原版的额度与付费逻辑。
